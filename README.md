# Features

- **HyprReady** – Built around the latest Hyprland, using its Lua config
- **Modular** – Small, focused config modules (`core`, `binds`, `look`, `rules`) that are easy to read and edit
- **Fast & Clean** – Smooth workflows that don't get in your way
- **Customizable** – Themes, scripts, and configs you can tweak
- **Arch First** – Works best on Arch and its derivatives

> [!IMPORTANT]
> This setup runs on keyboard shortcuts for pretty much everything.
> See the full [Keybindings](https://github.com/Pahasara/HyprDots/wiki/Keybindings) for details.

# Quick Start

```bash
git clone --depth 1 https://github.com/Pahasara/HyprDots.git
cd HyprDots
./install.sh
```

The installer backs up your existing configs (to `~/hyprdots_backup_*`), installs the packages, syncs the dotfiles, sets up GTK, cursors and Zsh, and enables the user services. Dev tools and gaming packages are optional and asked about separately. Details are in the [Installation guide](https://github.com/Pahasara/HyprDots/wiki/Installation).

# Core Components

| Component | Description |
|-----------|-------------|
| **Hyprland** | Wayland Compositor (Lua config) |
| **uwsm** | Systemd session manager for Hyprland |
| **Waybar** | Status Bar |
| **Rofi** | Launcher & Menus |
| **Dunst** | Notification Daemon |
| **Hyprlock / Hypridle** | Lock Screen / Idle Daemon |
| **awww** | Wallpaper Daemon |
| **Kitty + Zsh** | Terminal and Shell (Zinit, Starship) |
| **Neovim** | Text Editor |
| **Yazi** | TUI File Manager |
| **mpv** | Video Player (ModernZ, thumbfast, Anime4K) |

# Quick Shortcuts

| Shortcut | Action |
|----------|--------|
| `Super + Space` | App launcher |
| `Super + Return` | Terminal |
| `Super + E` | File explorer (GUI) |
| `Super + X` | Power menu |
| `Super + W` | WiFi menu |
| `Super + Q` | Close window |
